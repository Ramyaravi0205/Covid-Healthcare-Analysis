# COVID-19 Healthcare Performance Analysis

## 📌 Project Overview

This project presents an interactive **COVID-19 Healthcare Performance Analysis Dashboard** developed using **Power BI**. The dashboard provides a comprehensive overview of global COVID-19 statistics, including confirmed cases, active cases, recoveries, and deaths across countries, continents, and WHO regions. It enables users to monitor pandemic trends and gain data-driven insights through interactive visualizations.

## 🎯 Objectives

* Analyze global COVID-19 healthcare data.
* Track confirmed, active, recovered, and death cases.
* Compare COVID-19 impact across countries and WHO regions.
* Visualize trends using interactive charts and KPIs.
* Support data-driven decision-making through healthcare analytics.

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX (Data Analysis Expressions)**
* **Data Visualization & Dashboard Design**

## 📊 Key Features

* KPI Cards for Total Confirmed Cases, Active Cases, Recoveries, and Deaths.
* Country-wise COVID-19 case analysis.
* WHO Region and Continent-wise performance comparison.
* Monthly and daily trend analysis of confirmed cases.
* Interactive filtering and drill-down capabilities.

## 📈 Dashboard Insights

* Identifies the countries and regions most affected by COVID-19.
* Highlights trends in confirmed, recovered, and active cases.
* Enables comparison of healthcare impact across different geographical regions.
* Provides a clear visual representation of pandemic progression.

## 🔑 Key Metrics

* Total Confirmed Cases
* Total Active Cases
* Total Recovered Cases
* Total Death Cases
* Cases by Country/Region
* Cases by WHO Region
* Cases by Continent

## 🚀 Outcome

Developed an interactive healthcare analytics dashboard that transforms COVID-19 data into meaningful insights, helping users understand global pandemic trends and regional healthcare performance effectively.
